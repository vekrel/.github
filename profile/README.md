Vekrel runs your coding agents on your own machines, around the clock, and lets you follow and steer them from the web, the desktop app or your phone. Highly inspired by [T3 Code](https://github.com/pingdotgg/t3code).

It is early and not released yet.

| Repository | What it is |
|---|---|
| [web](https://github.com/vekrel/web) | Browser client, hosted at [app.vekrel.com](https://app.vekrel.com) |
| [desktop](https://github.com/vekrel/desktop) | Desktop app (Electron) |
| [mobile](https://github.com/vekrel/mobile) | iOS and Android app |
| [relay](https://github.com/vekrel/relay) | Cloud relay in Rust: accounts, machine links, tunnels, push |
| [daemon](https://github.com/vekrel/daemon) | Rust daemon that runs on your machine |
| [engine](https://github.com/vekrel/engine) | Reference Node engine, being replaced by the Rust daemon |
| [shared](https://github.com/vekrel/shared) | Shared TypeScript packages used by the clients |

Code is AGPL-3.0. Contact: [info@vekrel.com](mailto:info@vekrel.com).
